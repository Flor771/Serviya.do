# PLATE RUSH 🇩🇴

**The Dominican Street Game**

PLATE RUSH is an original arcade game inspired by the traditional Dominican street game commonly known as La Placa / La Plaquita.

## MVP
- Touch controls
- Batting
- Ball physics
- Running between two plates
- Basic defense
- Runs and outs
- Simple AI
- Match result
- Android-ready Godot 4 project

## Engine
Godot 4.x

## Run
1. Open this repository as a Godot project.
2. Open `scenes/Main.tscn`.
3. Press Play.

The first release intentionally focuses on a small playable core before online multiplayer and monetization.

## Android / Google Play
Export the project from Godot as an Android App Bundle (.aab). Configure the package name and signing key in the Godot Android export settings before publishing.
